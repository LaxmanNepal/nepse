# Generated Stock Page Architecture

Every listed company has a canonical static route:

`/stock/<symbol>/`

Examples:
- `/stock/hfin/`
- `/stock/akjcl/`
- `/stock/api/`

The generated page must use the same UI and application shell as `company.html`, while loading a company-specific JSON payload generated by GitHub Actions.

## Required files per company

```text
stock/<symbol>/
  index.html
  data.json
```

`data.json` contains the latest normalized snapshot plus historical/intraday records available at generation time. The page is generated automatically; no company page is manually maintained.

## Search flow

1. Navigation search is focused.
2. Load the generated stock index.
3. Show company names/symbols directly below the search box.
4. Selecting a company navigates to `/stock/<symbol>/`.
5. The generated page renders the same comprehensive company research UI as `company.html`.

## Refresh flow

GitHub Actions regenerates all company pages from the source dataset. A minute collector updates market snapshots during the Nepal trading session. The workflow must be idempotent and must not create duplicate historical records.

## Important

Do not manufacture buyer/seller/holder counts. Only display order-book/trade-side counts when the upstream source actually provides them. Technical BUY/HOLD/SELL is a calculated signal and must be labelled as such.
