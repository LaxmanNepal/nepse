# Nepali Finance News

The `/news/` section is a Nepali-language finance and capital-market news hub.

## Data policy

`data/news-sources.json` stores the approved source registry (RSS/Atom/sitemap/feed URLs where publicly available). The collector should store headlines, links, publication times, source names and categories. It must not copy full copyrighted articles. The site should show the headline, short metadata/summary where permitted, and link to the original article.
