# NEPSE Signal Engine — validation and indicator rules

The signal file is generated by `scripts/generate_ai_signals.py`.

## Indicators
- RSI(14) from at least 15 sequential closes.
- SMA(20), SMA(50).
- EMA(12), EMA(26).
- MACD(12,26,9) line, signal and histogram.
- Relative volume = current session volume / mean of the prior 20 sessions, when history provides it.
- Daily range position = (LTP - low) / (high - low).

## History input
The engine attempts to load a symbol history from:
- `data/history/SYMBOL.csv`
- `data/history/SYMBOL.json`
- `stock/symbol/history.json`
- `stock/symbol/data.json`

The file must contain chronological rows with close/LTP/price and optionally volume/quantity. The engine does not scrape or infer missing candles. If usable history is unavailable, it falls back to snapshot-only scoring and cannot issue an outright BUY.

## Signal labels
- BUY ON CONFIRMATION: requires at least 50 closes, calculated trend/momentum indicators, positive session momentum, RSI 48–70, positive MACD histogram, price above SMA20, adequate relative volume when available, strong daily range position and score >= 78.
- WATCH BREAKOUT: snapshot-only candidate; not a buy instruction.
- WAIT: confirmation or history is missing.
- AVOID: weak price action under this heuristic.
- SELL / REDUCE (REVIEW HOLDING): bearish technical screen for an existing holding. It does not mean short-sell the stock.

## Scoring
A transparent heuristic score blends momentum, daily range position, turnover and volume. When technical data exists, 35% of the total score is replaced with the trend/RSI/MACD technical subscore. The score is NOT a probability of profit.

## Risk output
Entry/stop/targets are scenarios, not guarantees. Position size must be calculated separately from the user's capital, maximum risk, fees and available cash. Do not claim exact net P/L unless transaction costs are configured.
